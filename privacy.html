Privacy Policy — YouTube Uploader

Last updated: 2026-11-06 (scopes revised)

Who uses it

YouTube Uploader is used only by its owner, to manage the owner's own YouTube channels. Nobody else signs in to it.

What it accesses

With the owner's permission (Google OAuth), it uses the YouTube Data API to read basic information about the owner's own channel (channel id, title, description) and the owner's uploaded videos (processing status, privacy status, view counts). It uploads videos and thumbnails that the owner made, and changes the privacy status or scheduled publish time of the owner's own uploads. Scopes: youtube.upload, youtube.force-ssl.

Storage and sharing

The OAuth token is stored only on the owner's own computer. The tool has no server and keeps no database. It does not collect, sell, share or transfer any user data to anyone. Data from Google APIs is used only to upload and check the owner's own videos.

Google API Services User Data Policy

The use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
